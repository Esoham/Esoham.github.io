# Business Analyst Portfolio

Static, responsive portfolio site for Esoham Abalo. Includes VerityFlow, FluxPilot and ChangeGuard MFG case-study links, professional experience and education.

## Publish with GitHub Pages
For the personal site URL `https://esoham.github.io`, rename this repository to `Esoham.github.io` in **Settings → General → Repository name**. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`. GitHub may take a few minutes to deploy.

This site uses HTML/CSS without external dependencies or analytics tracking. Project datasets are synthetic; no production outcomes are claimed.
