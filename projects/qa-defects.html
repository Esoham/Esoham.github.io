FF-BUG-01 — About navigation reached a missing route

Medium · Navigation

Historical reproduction: Open the FarmFresh catalog, then select the About link from the navigation.

Expected: The About page should display and explain what the fictional application does.

Actual before repair: The destination route did not exist, so the navigation failed.

Resolution: Added an About endpoint and template, then updated Flask route checks and Playwright navigation coverage.

Regression evidence: UI navigation assertion · Route checks.

FF-BUG-03 — Cart action did not update visible state

Medium · Functionality

Historical reproduction: Open Products and select Add to Cart for one or more sample products.

Expected: A visible cart count and subtotal should update; the user should be able to clear the simulated cart.

Actual before repair: The interface showed only an alert; it did not maintain cart state.

Resolution: Added a visible cart count, subtotal and clear-cart control.

Regression evidence: UI test checks 0 items → $2.99 → $7.49 → reset.

FF-BUG-04 — Dynamic product HTML used an unsafe insertion pattern

High potential risk · Security hardening

Historical reproduction concept: Review the prior rendering path for product-card values supplied by the API. Product strings were interpolated into innerHTML and inline JavaScript instead of rendered as inert text.

Expected: Data from the catalog should display as text and must not execute as HTML or script.

Observed risk before repair: Unsafe rendering could allow markup injection if untrusted product values reached the sink. This is a code-level security finding, not evidence of a successful production exploit.

Resolution: Switched to DOM node construction with createElement and textContent, plus controlled adversarial input tests.

Regression evidence: Rendering code · Markup-input browser test.

Source of defect IDs and historical observations: Agile QA strategy & repair log. The historical version was not re-run during this portfolio write-up. No screenshot is supplied where none was documented.

Reproduction quality

Release decision

Retest the original failure, execute relevant regression coverage, document any remaining risk, and distinguish confirmed security impact from a potentially unsafe pattern.
