Vanessa Voice AI

A voice AI acquisitions assistant prototype built with React, Node.js, Express, Vapi, and GPT-4. This project is separate from my SentinelWatch security operations lab.

View source and setup documentation · See SentinelWatch security case study

Problem

Acquisitions teams need a consistent way to initiate outreach, capture seller intent, track call outcomes, and route qualified leads for human follow-up.

Implementation

  • React dashboard for call history, contact queue, and outcome visibility.
  • Express backend endpoints to initiate and inspect outbound calls.
  • Vapi voice-agent integration using GPT-4-based conversations and qualification flow.
  • Lead-transfer and callback concepts documented in the repository.

Architecture

React interface → Express API → Vapi voice service → call status and outcome reporting. Provider credentials are configured through environment variables rather than committed source.

Security and responsible deployment

The repository identifies authentication, rate limiting, persistent storage, and telemarketing consent/compliance as work required before production use. The public repository demonstrates a prototype; it does not establish production readiness, successful real-world call volume, or measured conversion results.
