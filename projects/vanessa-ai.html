Vanessa Voice AI

Can a voice assistant help a real-estate acquisitions workflow collect seller intent and route qualified conversations to a human? Vanessa explores this problem using a React interface, Express API, and configurable Vapi/GPT-4 integration.

The workflow problem

Outreach teams need a consistent way to track attempts, classify intent, document callbacks and opt-out requests, and escalate potential leads to human staff. A voice agent must preserve human control and respect consent and compliance requirements.

My implementation

  • Built a React dashboard concept to surface contact queues, call progress, outcomes and history.
  • Structured Express API endpoints and Vapi service integration for initiation and call-status workflows.
  • Documented conversation qualification and human handoff scenarios in the README.
  • Separated provider credentials from tracked source through environment configuration.

Architecture and review path

React dashboard → Express API → Vapi service/AI conversation → status and outcome information.

To evaluate this prototype, start with the README and setup instructions, inspect the backend source and frontend source, then compare the implementation against the described scenarios.

Testing, limitations and next steps

  • Demonstration scope: The source repository describes the voice-call workflow and UI, but the portfolio does not claim measured lead conversion, live production traffic, or automated end-to-end test coverage.
  • Safety: Deployment would require verified consent, opt-out handling, privacy safeguards, authentication, rate limits and applicable calling-law compliance.
  • Engineering next steps: Add isolated API tests, mocked Vapi responses, input validation, persistence, role-based access controls and transparent error states.
