# Providence Meridian Group LLC — Website staging

This is the **unpublished staging branch** for the company's independently owned B2B sourcing and procurement website.

## Current state
- Site source code is built locally and saved in the conversation artifact `providence-meridian-website.zip`.
- The full production files have **not yet been committed to this GitHub branch**.
- Do **not** merge this branch into the GitHub Pages default branch yet; the inquiry form is intentionally disabled until a verified recipient and endpoint are connected.
- Planned final destination: a dedicated, company-controlled repository and a custom .com domain, with Cloudflare Pages free-tier hosting.

## Site scope
Responsive mobile-first home, sourcing categories, how it works, business overview, short non-sensitive buyer inquiry form, and draft privacy and terms pages.

## Before launch
1. Import the ZIP source into a dedicated repository or staging folder, without duplicating its nested directory structure.
2. Acquire and configure the owner's domain. Set DNS, HTTPS, and email forwarding.
3. Set up a two-way outbound email solution and a form provider; update `config.js` with a verified form endpoint.
4. Test real form delivery and keyboard/mobile behavior, finalize privacy/terms, and check College Park license guidance.
5. Validate supplier/referral fee agreements before making commercial promises.

**Business model:** No inventory, no resale, no title transfer. Providence earns agreed commissions or service fees for supplier introductions and sourcing coordination.
